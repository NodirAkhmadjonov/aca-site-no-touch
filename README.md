# aca-site-no-touch

Собранный сайт Агентства по противодействию коррупции — **артефакт сборки,
не трогайте руками.** Любая правка здесь будет затёрта при следующей публикации.

Источник: приватный репозиторий `aca-design-system`, каталог `deploy/`.
Публикация: `python -X utf8 tools/publish_site.py` оттуда.

Открыть: https://nodirakhmadjonov.github.io/aca-site-no-touch/
